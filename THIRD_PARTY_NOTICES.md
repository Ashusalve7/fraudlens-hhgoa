# Third-party and dataset notices

FraudLens is an original hackathon implementation built for the Hacker House Goa 2026 TigerGraph challenge.

## Dataset

The project processes the anonymized IEEE-CIS/Vesta fraud investigation dataset supplied by the organizers in `HHGOA_IEEE/`. The sponsor README is authoritative for attribution, transformations, usage rules, case semantics, and answer format. The raw dataset is not redistributed by this repository.

## Runtime dependencies

The application uses open-source packages including Python, pandas, pyarrow, scikit-learn, FastAPI, Uvicorn, pyTigerGraph, the Model Context Protocol SDK, Node.js, React, React Router, Recharts, and Vite. Their respective licenses apply.
